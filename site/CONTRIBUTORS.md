# Contributors

RusDox credits people from the repository's actual Git history and merged pull
requests. No contributor names are invented for marketing.

## People

- [Othmane Blial](https://github.com/OthmaneBlial) — creator and current maintainer; document engine, CLI, parity lab, templates, documentation, distribution, and release infrastructure.

## Automation

- [Dependabot](https://github.com/dependabot) — dependency update pull requests.

New human contributors are added here and to the relevant release notes when a
meaningful change is merged. A commit or pull request can use a corrected author
identity through `.mailmap`; private email addresses are never published by the
site generator.

Start with the [`good first issue`](https://github.com/OthmaneBlial/rusdox/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22)
queue, read [Contributing](CONTRIBUTING.md), or share a real output in
[Show and tell](https://github.com/OthmaneBlial/rusdox/discussions/categories/show-and-tell).
