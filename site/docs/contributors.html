RusDox credits people from the repository's actual Git history and merged pull requests. No contributor names are invented for marketing.

People

  • Othmane Blial — creator and current maintainer; document engine, CLI, parity lab, templates, documentation, distribution, and release infrastructure.

Automation

  • Dependabot — dependency update pull requests.

New human contributors are added here and to the relevant release notes when a meaningful change is merged. A commit or pull request can use a corrected author identity through .mailmap; private email addresses are never published by the site generator.

Start with the good first issue queue, read Contributing, or share a real output in Show and tell.
